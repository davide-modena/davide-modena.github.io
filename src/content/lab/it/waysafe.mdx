## L'idea

Una web app che calcola percorsi sicuri, mostra il livello
di sicurezza delle zone, raccoglie segnalazioni geolocalizzate e ha un pulsante di emergenza.

API REST documentata con OpenAPI, frontend React con mappe Leaflet.
